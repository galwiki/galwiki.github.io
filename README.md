# 🎮 Galgame Wiki

**一个由玩家共建的 Galgame 知识库**

主站：[https://www.galgame.it/wiki](https://www.galgame.it/wiki)


## 这是什么？

Galgame Wiki 是一个**专门收录 Galgame（美少女游戏/视觉小说）相关知识的中文百科站点**。

你可以把它理解为：**一本关于 Galgame 的在线百科全书，而且每个人都可以参与编写。**

目前站内已收录 **102+ 个条目**，注册用户超过 **8 万人**。


## 为什么要做这个？

玩 Galgame 的人应该都有过这样的经历：

想查一个游戏的资料，贴吧翻一遍，论坛搜一遍，再跑去 VNDB 看英文，折腾半天还是找不到满意的中文介绍。

想了解某个术语的意思，搜出来的解释五花八门，没人告诉哪个是对的。

想找某个老游戏的技术解决方案，帖子可能是八年前发的，链接早就失效了。

**信息是有的，但太散了。**

Galgame Wiki 想做的事情很简单：**把散落在各处的信息汇集到一起，让想查东西的人，能一站式找到答案。**


## 站里有什么？

目前站内分为十几个板块，覆盖了玩家最常需要的信息：

| 板块 | 内容包括 |
|------|----------|
| **概念** | Galgame 圈内的术语和“黑话”，新人入坑必备 |
| **Galgame工具** | 游戏引擎、模拟器、翻译工具等资源 |
| **运行问题** | 黑屏、闪退、乱码等问题的解决方案 |
| **游戏资料库** | 按会社分类的作品档案 |
| **游戏事件** | 行业发展中的重要事件 |

期刊地址：[https://journal.galgame.it](https://journal.galgame.it)


## 我们的原则

- **完全免费**：所有内容无条件开放，不设付费墙
- **无广告**：不插入任何商业广告
- **财务透明**：年度运营支出公开
- **开放编辑**：欢迎任何人参与贡献
- **尊重版权**：引用他人内容必标来源


## 谁在用？

目前已有多个 Galgame 相关站点的游戏元数据由 Galgame Wiki 统一维护——它正在成为社区的基础设施之一。

也有研究者在这里找到了其他地方查不到的资料，完成了学术论文。

**有人用，就值得。**


## 如何参与？

不需要你是大佬，也不需要会写代码。

哪怕只是：
- 修正一个错别字
- 补充一条发售日期
- 添加一个游戏封面图
- 完善一个会社的介绍

**都是在帮忙。**

如果你想做更多，可以：
- 整理你熟悉的游戏或会社词条
- 提供圣地的实景照片或坐标
- 翻译日文或英文资料
- 向《Galgame研究》期刊投稿
